# 게임 모드 범위 정정

## 정정 배경

`custom-piece-design.md`에 경쟁전과 친선전 모드 구분, `GameMode` 도입,
경쟁전에서의 커스텀 기물 차단이 구현 계획인 것처럼 잘못 기재되어 있었다.
해당 내용은 현재 프로젝트 범위로 확정된 요구사항이 아니므로 설계 문서에서
제거했다.

## 현재 프로젝트 범위

- 현재 프로젝트에는 경쟁전 추가 계획이 없다.
- 경쟁전과 친선전을 구분하는 게임 모드 시스템도 현재 구현 범위가 아니다.
- 기존 멀티플레이어 동작을 임의로 경쟁전 또는 친선전으로 재해석하지 않는다.
- `GameMode`, 경쟁전 전용 정책, 경쟁전 전용 API·UI·테스트를 이 문서를
  근거로 구현하지 않는다.

향후 게임 모드 기능이 필요해지면 별도의 명시적인 요구사항과 설계 검토를
거쳐 새 계획으로 추가한다. 이 정정은 현재 기능을 삭제하거나 기존 동작을
변경하지 않으며, 문서에 잘못 포함된 미래 계획만 바로잡는다.
