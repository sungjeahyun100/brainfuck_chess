# 기물 스펙

- 기물 이름: 희생의 성소
- 기물 점수: 8점
- 기물 배치: 뒷줄

체섬블리 코드:

take-move(1, 0);
take-move(0, 1);
take-move(-1, 0);
take-move(0, -1);
take-move(1, 1);
take-move(1, -1);
take-move(-1, 1);
take-move(-1, -1);

능력: 희생
자신을 클릭해 발동한다.
자신 주변 8칸의 모든 아군 기물(킹 제외)을 제물로 바쳐 죽이고, 합계 8점 한도 안에서 제물 점수 이하의 상대 지상 기물을 플레이어가 선택해 죽인다.
AI는 같은 점수 한도 안에서 별도의 제한된 선택 로직으로 제거 대상을 정한다.
- 쿨타임: 2턴

특이사항:
만약 자신 주변의 8칸 전부 희생양 기물로 채워져 있을 경우, 상대 킹을 잡을 수 있다.
